# High-End Visual Design

## Core Principles
1. **Space is Luxury**: Use generous padding and margins. Elements should never feel cramped. Use a 4pt/8pt grid system rigorously.
2. **Typography Matters**: Avoid generic fonts. Pair a strong serif (like Playfair Display or Merriweather) with a clean geometric sans-serif (like Inter or Geist). Ensure high line-height (1.6+) for readability.
3. **Subtle Elevation**: Shadows should be soft, large, and low-opacity (e.g., ox-shadow: 0 20px 40px rgba(0,0,0,0.05)). Never use harsh borders on luxury cards.
4. **Restrained Color Palette**: Use monochromatic or analogous color schemes. Use one distinct accent color very sparingly for primary actions. Backgrounds should be off-white (e.g., #FAFAFA) rather than pure #FFFFFF.
5. **Micro-interactions**: Hover states should be smooth and deliberate. Use CSS transitions (e.g., 	ransition: all 0.3s cubic-bezier(0.25, 1, 0.5, 1)).

## Implementation
- Always enforce these rules when designing or modifying UI components.
- Reject overly colorful or cluttered designs.
